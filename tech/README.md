# 技术单审核台

> 审核系统的一个功能，网址 `tech/`。系统总说明见上一层的 `README.md`。

上传技术单（多个 `.xlsx`，或整包 `.zip`），网页按审核规则自动标红、分文件、改页脚，然后下载转发给专家。

所有处理都在浏览器里完成，技术单不会上传到任何服务器。

## 怎么用

网页分三步，最上面的步骤条可以随时切换：

1. **上传**：把技术单（多个 `.xlsx` 或整包 `.zip`）拖进来，确认「今日设置」里的制表日期和审核人。进阶设置（分男女款的手表、要先问的产品、加急字眼）收在下面，审核规则也可以点开看。
2. **处理待办**：上面一句告诉你「还有几件事要你决定」。
   - 左边分类：待你决定、有问题、特殊加急、新生儿、家人订单、要留意、没问题，点一下就筛选；中间可以搜姓名或订单号。
   - 待办卡片：要问下单者 / 先问能不能做 / 换购没原单号 → 「没问题，放回普通文件」或「放有问题文件」，话术一键复制；备注只写祝福语 → 「标红 / 不标红」，多个可以一起选。决定过的收进「已决定」，可以再改。
   - 「按文件看」列出每一单；按「打开」，右边显示全部资料，可以直接改（改过的变红字）、每格「设红字」或取消红字、标为有问题。
   - 最下面的黑色栏一直在，按「去下载」。
3. **下载**：确认制表日期、审核人、国内 / 海外；还没决定的事会提醒。勾选要下载的：
   - 没问题的：一个 zip，`技术单 日期（全部单数）H.zip`
   - 特殊加急：不放进 zip，一个个文件下载
   - 有问题的：另一个 zip，`有问题技术单 日期（单数）H.zip`
   - 新生儿：单独一个文件，新生儿放在最前面，例：`新生儿名正言顺技术单 14.10.2026（1）H.xlsx`
   - 每个文件也可以「单独下载」

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 网页（界面、上传、下载） |
| `review-engine.js` | 审核规则引擎（标红、分文件、文件名、页脚） |

用到的库放在上一层的 `vendor/`：ExcelJS 4.4.0、JSZip 3.10.1（本地没载入时才从 jsdelivr 载入）。

## 审核规则（摘要）

完整规则在网页第 1 步下面的「审核规则手册」：一张「每单去哪个文件」流程图、标红速查表、子时和立春两条时间轴，以及「要问谁」「文件名」「回传时间」三张表。可以「预览 / 打印」，也可以「下载规则」（排好版的 .html 文件，打印时可以另存为 PDF）。


- 只改字体颜色，不动位置、大小、合并格；红色一律用红字，原文件涂的底色也改成红字
- 子时：前子时 23:00–23:59 生日加一天，后子时 00:00–00:59 不加；「是否子时」写是 → 时间栏红字（备注见下）；时间和「是否子时」对不上 → 问下单者
- 订单状态备注有内容、备注有人名 / 曾用名 / 订单号（原订单号）/ 加急字眼 / 日期 / 出生时间 / 起名要求（少笔画等）/ 要求保留某个字 / 某个字的写法、字形 → 红字
- 繁体、子时：备注有相关内容才自动红；只有祝福语 → 待确认，由审核人选
- 总备注和备注一字不差 → 清空总备注
- 任何一格写了暂缓 / 暂停 → 红字 + 有问题，不放进给专家的文件（戒指的指环尺寸写暂缓不算，只标红）
- 加急（加急、急、快，或一个月内的日期）→ 单独文件（特殊加急），订单详情里可以按「设为特殊加急 / 不加急，放回普通文件」手动改；未满一岁 → 新生儿文件
- 名正言顺：每位学员两行；名册展示繁体（备注见上）、双胞胎 / 三胞胎红字（老大父亲生日、老二母亲生日、老三父母生日也红）；姓氏和使用人姓名简繁不同或更换姓氏 → 红字；和父亲不同 → 有认祖归宗红字给专家，没有就问下单者；父母同名 → 问下单者；生肖按立春核对
- 天解 / 天泽手表、福运戒指、天恒手表 → 有问题，先问能不能做；换购单「原订单编号」空的 → 有问题
- 家人订单：父母 / 兄弟姐妹 / 子女 / 备注等任何一栏写了别的单的订单号、姓名或它的父母兄弟姐妹名字，而那张单也在同一个文件里 → 同一家（每个文件单独审核，不跟别的工具的单连起来），导出的文件里同一家排在一起，几家人一家接一家，中间不夹别人的单，整行涂同一个颜色（蓝、绿、黄、橙…），不同家不同颜色
- 只有天威、天富手表分男款、女款文件
- 页脚：审核人 martin；制表时间今天；回传时间名正言顺 +1 个月（新生儿名正言顺 +7 天），九合牌、吊坠 +7 天，其他 +10 天
