# 审核系统上线步骤（阿里云 OSS 香港 + 自己的域名）

放在香港区，**不用 ICP 备案**，国内打开快。全部做完以后，每次合并到 `main`，网站会自动更新。

> 阿里云控制台的按钮名称偶尔会改，下面写的是目前的叫法。找不到的话，在控制台最上面的搜索框搜关键字。

要准备的：阿里云账号（已实名）、一张能付款的卡或支付宝，大约 1 小时，加上域名实名认证的等待时间（一般 1–3 天）。

## 1. 买域名、做域名实名认证

1. 打开阿里云「域名注册」，搜一个想要的名字，例如 `xxx-shenhe.com`，买下来
2. 买的时候会要你选「域名持有者信息模板」，按提示上传身份证或营业执照，做**域名实名认证**
3. 等认证通过（控制台「域名列表」里状态变成正常）。**没通过之前域名打不开**

> 这是「域名实名认证」，不是「ICP 备案」。放香港区只需要前者。

## 2. 建 OSS Bucket（放网站的地方）

1. 打开「对象存储 OSS」→「Bucket 列表」→「创建 Bucket」
2. 填：
   - Bucket 名称：例如 `shenhe-site`（全阿里云唯一，被用了就换一个）
   - 地域：**中国香港**
   - 存储类型：标准存储
   - 读写权限：**公共读**（如果提示「阻止公共访问」开着，先把它关掉，再改成公共读）
3. 进入这个 Bucket →「数据管理」→「静态页面」→「设置」：
   - 默认首页：`index.html`
   - 子目录首页：**开通**（这样 `/name/`、`/tech/` 才能打开）
   - 文件 404 规则：Redirect
   - 默认 404 页：不填

## 3. 绑定域名

1. Bucket →「Bucket 配置」→「域名管理」→「绑定域名」
2. 填你的网址，例如 `shenhe.xxx-shenhe.com`（也可以直接用 `xxx-shenhe.com`）
3. 域名也在这个阿里云账号里的话，勾「自动添加 CNAME 记录」；不是的话，按页面显示的 CNAME 到域名那边手动加一条解析

## 4. 开 HTTPS（建议）

不开也能用，但浏览器会显示「不安全」。

1. 打开「数字证书管理服务」→「SSL 证书」→ 申请免费证书（个人测试证书），域名填上一步的网址，按提示验证
2. 签发后回到 OSS「域名管理」，在这个域名的「证书托管」选刚申请的证书
3. 免费证书大约 3 个月要续一次，阿里云会发提醒

## 5. 建一个只能上传的钥匙

不要用主账号的钥匙。建一个只能往这个 Bucket 放文件的子账号：

1. 打开「RAM 访问控制」→「身份管理」→「用户」→「创建用户」
2. 登录名称：`shenhe-uploader`；访问方式：勾「使用永久 AccessKey 访问」（或叫「OpenAPI 调用访问」）
3. 建好后会显示 **AccessKey ID** 和 **AccessKey Secret**，**Secret 只显示这一次**，先复制到安全的地方
4. 「权限管理」→「权限策略」→「创建权限策略」→ 脚本编辑，贴下面这段（把 `shenhe-site` 换成你的 Bucket 名称），命名 `shenhe-upload`：

   ```json
   {
     "Version": "1",
     "Statement": [
       {
         "Effect": "Allow",
         "Action": ["oss:PutObject"],
         "Resource": ["acs:oss:*:*:shenhe-site/*"]
       }
     ]
   }
   ```

5. 回到「用户」→ `shenhe-uploader` →「添加权限」，选刚建的 `shenhe-upload`

> AccessKey 不要贴到聊天、邮件或代码里。只放到下一步的 GitHub Secrets。

## 6. 把钥匙交给 GitHub

1. 打开 GitHub 上的 `seet0624/internalanalysis` →「Settings」→「Secrets and variables」→「Actions」
2. 「New repository secret」，加三个：

   | Name | Secret |
   |---|---|
   | `OSS_ACCESS_KEY_ID` | 第 5 步的 AccessKey ID |
   | `OSS_ACCESS_KEY_SECRET` | 第 5 步的 AccessKey Secret |
   | `OSS_BUCKET` | Bucket 名称，例如 `shenhe-site` |

   （Bucket 不在香港才要加第四个 `OSS_REGION`，例如 `oss-cn-shenzhen`）

## 7. 上线

- 「Actions」→ 左边「上线到阿里云 OSS」→「Run workflow」，选 `main`，按绿色按钮
- 以后每次合并到 `main` 会自动上传，不用再按
- 看到绿色打勾就打开你的网址，例如 `https://shenhe.xxx-shenhe.com`

## 打不开怎么办

| 情况 | 看哪里 |
|---|---|
| 打开变成下载文件 | 用的是 OSS 默认网址（`xxx.oss-cn-hongkong.aliyuncs.com`）。要用第 3 步绑的域名 |
| 首页能开，点功能 404 | 第 2 步「子目录首页」没开通 |
| 403 AccessDenied | 第 2 步读写权限不是「公共读」，或「阻止公共访问」还开着 |
| 完全打不开 | 域名实名认证还没通过，或 CNAME 解析还没生效（最多等 10 分钟） |
| Actions 红叉 | 点进去看「上传」那一步的错误；多半是 Secrets 填错，或 RAM 权限策略里的 Bucket 名称不对 |

## 大约花费

- 域名：`.com` 第一年几十元，之后每年约 80–90 元
- OSS：网站约 1.7 MB，同事打开一次大约下载 1.7 MB（之后组件有缓存）。十几个人每天用，一个月流量费大约几块钱

## 要知道的

- 没有登录，知道网址的人都能打开。网页里没有客户资料（技术单、名册只在各自的浏览器里处理），但审核规则（产品名、审核人名字等）看得到
- 上传只会新增 / 覆盖文件，不会删除。以后拿掉某个功能，要到 OSS 控制台把对应文件夹删掉
- 上传程序只传网页文件（`.html` `.js` `.css` 图片字体），`.xlsx` `.zip` `.json` 一律不传，防止把技术单或名字审核存档放上网
