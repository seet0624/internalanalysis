# 审核总部

国内同事用的审核网站。整个首页是一间 3D 公司：按真实办公室平面图规划（老板办公室、会议室、客服部开放办公区、各部门、茶水间、洗手间、前台、休息区、设施），员工会自己起身去茶水间、洗手间、会议室，再走回座位。点员工就能开始工作。审核工具在浏览器里处理，文件不会上传到任何服务器。不需要登录。

## 功能

| 网址 | 功能 | 说明 |
|---|---|---|
| `/` | 首页 | 3D 公司（可切「平面图」）、详细资料、组织架构。名单在 `hq/company.js` |
| `name/` | 名字审核组 | 名正言顺名册：核对新名（撞字、撞音、不雅谐音），转繁体，下载结果 |
| `tech/` | 技术单审核组 | 按规则标红、分文件、改页脚，下载给专家。详见 [`tech/README.md`](tech/README.md) |

每个功能左上角的「审核总部」可以回到首页。

## 公司名单（`hq/company.js`）

首页的 3D 公司和「组织架构」都按这份名单画，改名单就好，不用动 3D 程序：

- **客服部**（`main: true`）是主要办公区，分四个小组 `teams`，每组一块对坐的工位：名字审核组、技术单审核组、Claude 客服组、新功能工位
- **其他部门**：营销、财务、人事、法务、数据，各一间小办公室；东边最多 6 间
- 小组 / 部门的 `kind`：`site`（网站里的工具，点员工进入 `href`）、`claude`（Claude 里的 skill，点员工复制 `/插件:skill` 指令）、`planned`（空工位 / 空办公室）
- **设施** `facilities`：把连接器按用途分进收发室、档案室、会议室、设计工作室、影音室、机房
- **墙上的画** `art`：从 Unsplash 载入，载不到会换成程序画的抽象画

加新功能：把客服部的「新功能工位」改成 `kind: 'site'`，填上 `href` 和员工。

## 公司模拟

- **需求和心情**：每位员工有精力、饱足、如厕、社交、乐趣五项需求，坐着工作会慢慢下降；最低的那项掉到一半以下，员工会自己去补（累了泡咖啡、饿了去茶水间、无聊去休息区、想聊天去找同事）。五项平均就是心情
- **想法和对话**：员工起身时头上冒想法图示；找同事讨论、开会时会冒对话
- **游戏时钟**：左下角，真实 1 秒 = 游戏 1 分钟，08:00–20:00 一天；可以暂停、2 倍、4 倍速；天色跟着时间变
- **指挥员工**：点员工，资料卡里「叫他去」泡咖啡、吃点心、洗手间、开会、休息区、回座位
- **放低墙壁**：左下角，看清楚房间里面
- 需求、去处、对话的设定在 `hq/office.js` 开头的 `NEEDS`、`ACT`、`CHATS`
- 网址加 `?debug`，主控台可以用 `hqOffice`（例如 `hqOffice.info()` 看绘制次数）

## 国内访问

- 不用 Google 字体，改用电脑自带的中文字体（苹方、微软雅黑、宋体 / 细明体）
- ExcelJS 4.4.0、JSZip 3.10.1、Three.js 0.170.0 放在 `vendor/`，跟网站一起放，不依赖外网 CDN；Excel / zip 本地文件没载入时才退回 cdnjs / jsdelivr
- 唯一会连外网的是墙上的画（Unsplash），载不到不影响使用
- 显示不了 3D 的电脑，首页下面的「组织架构」一样可以用
- 整个网站是静态文件，放到任何能放网页的地方都能用

## 上线

放在阿里云 OSS 香港区，绑自己的域名，不用 ICP 备案。第一次设置照 [`deploy/上线步骤.md`](deploy/上线步骤.md) 做；设好以后，每次合并到 `main` 网站自动更新（`.github/workflows/deploy-oss.yml`）。

只看会上传哪些文件：`DRY_RUN=1 node deploy/upload-oss.mjs`

## 加新功能

1. 新建一个文件夹，例如 `contract/index.html`
2. 要读写 Excel 就用 `../vendor/exceljs.min.js`、`../vendor/jszip.min.js`
3. 页面左上角放一个 `<a href="../">审核总部</a>` 回首页
4. 在 `hq/company.js` 把客服部的「新功能工位」改成 `kind: 'site'`，填 `href` 和员工
5. 要在浏览器里存东西（`localStorage`），名字前面加上这个功能自己的前缀，避免和别的功能撞名。现在用的：名字审核 `mzys_`，技术单 `tsr-`
