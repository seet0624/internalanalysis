# 技术单审核台

上传技术单（多个 `.xlsx`，或整包 `.zip`），网页按审核规则自动标红、分文件、改页脚，然后下载转发给专家。

所有处理都在浏览器里完成，技术单不会上传到任何服务器。

## 怎么用

1. 打开 `index.html`（放到 GitHub Pages 后，网址是 `…/tech-sheet-review/`）。
2. 把技术单拖进左边，或点击选择文件。
3. 看「需要人工处理」和每一单的审核结果；按「查看 / 修改」可以看全部资料、直接修改（改过的格子会变红字），每个格子旁边的「设红字 / 红字 ✓」可以手动加红或取消红字；按「标为有问题」可以手动分出去。
   - 「备注要不要标红？」：繁体或子时的单，备注只写祝福语时不会自动标红，由你按「标红 / 不标红」（也可以全部一起选）。没选的不标红，下载前会提醒。
4. 下载：
   - 没问题的：一个 zip，`技术单 日期（全部单数）H.zip`
   - 特殊加急：不放进 zip，一个个文件下载
   - 有问题的：另一个 zip，`有问题技术单 日期（单数）H.zip`
   - 要确认的单（天解 / 天泽 / 福运戒指 / 天恒、没有原订单编号的换购单）：话术框可以一键复制

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 网页（界面、上传、下载） |
| `review-engine.js` | 审核规则引擎（标红、分文件、文件名、页脚） |

用到的库从 cdnjs 加载：ExcelJS 4.4.0、JSZip 3.10.1。

## 审核规则（摘要）

- 只改字体颜色，不动位置、大小、合并格；红色一律用红字，原文件涂的底色也改成红字
- 子时：前子时 23:00–23:59 生日加一天，后子时 00:00–00:59 不加；「是否子时」写是 → 时间栏红字（备注见下）；时间和「是否子时」对不上 → 问下单者
- 订单状态备注有内容、备注有人名 / 曾用名 / 订单号（原订单号）/ 加急字眼 / 日期 / 出生时间 / 起名要求（少笔画等）/ 要求保留某个字 → 红字
- 繁体、子时：备注有相关内容才自动红；只有祝福语 → 待确认，由审核人选
- 总备注和备注一字不差 → 清空总备注
- 加急（加急、急、快，或一个月内的日期）→ 单独文件（特殊加急）；未满一岁 → 新生儿文件
- 名正言顺：每位学员两行；名册展示繁体（备注见上）、双胞胎 / 三胞胎红字（老大父亲生日、老二母亲生日、老三父母生日也红）；姓氏和使用人姓名简繁不同或更换姓氏 → 红字；和父亲不同 → 有认祖归宗红字给专家，没有就问下单者；父母同名 → 问下单者；生肖按立春核对
- 天解 / 天泽手表、福运戒指、天恒手表 → 有问题，先问能不能做；换购单「原订单编号」空的 → 有问题
- 家人订单：父母 / 兄弟姐妹 / 子女 / 备注等任何一栏写了别的单的订单号或姓名，而那张单也在这次上传里 → 同一家，整行涂同一个颜色（蓝、绿、黄、橙…），不同家不同颜色
- 只有天威、天富手表分男款、女款文件
- 页脚：审核人 martin；制表时间今天；回传时间名正言顺 +1 个月，九合牌、吊坠 +7 天，其他 +10 天
