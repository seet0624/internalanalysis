# 审核总部

国内同事用的审核网站。整个首页是一间 3D 公司：按真实办公室平面图规划（老板办公室、会议室、客服部开放办公区、各部门、茶水间、洗手间、前台、休息区、设施）。客服在审核工具处理文件后，公司里对应的员工会照流程走去交资料、对话，老板看得到全部。审核工具在浏览器里处理，文件不会上传到任何服务器。

## 登入

| 账号 | 看得到 |
|---|---|
| `dongfangcs` | 国内客服部：首页一打开就是「功能」（名字审核、技术单审核最大）、3D 客服部、资料库、指挥中心 2F；其他部门、老板办公室锁住 |
| `martin` | 老板：全公司、今天的审核总览 |

- 账号在 `hq/auth.js` 的 `ACCOUNTS`，存的是密码的 SHA-256（加盐），不是明码；加账号：在主控台 `HQAuth.hash('账号', '密码')` 算出来贴进去
- 每一页都载入 `hq/auth.js`：没登入就带回首页登入，登入后回到原来那一页；登入 12 小时有效
- **这是网页登入**：挡得住一般人，但检查写在网页里、仓库是公开的，懂技术的人可以绕过；密码 `123` 也太容易猜。敏感资料不要放进网站，正式用之前换掉密码

## 审核 → 员工交接（`hq/bus.js`）

- 名字审核读完名册、技术单审核处理完 / 下载完，会记一笔事件（几张、几张有问题、要问下单者几单……真实数字）
- 3D 公司收到事件（同一个浏览器的其他分页会即时收到；回到首页会补演上次之后的纪录），员工照 `hq/company.js` 的 `workflows` 一步步走去交资料：说话带真实数字、对方回话，「公司对话」里都看得到
- 没有审核纪录时，「公司对话」可以「播放一次示范」，示范的对话会标「示范」
- **纪录存在这台电脑的浏览器里**，不会上传：客服电脑上的纪录，老板在另一台电脑看不到。要跨电脑共享，需要一个服务器存纪录

## 公司名单（`hq/company.js`）

首页的 3D 公司和「组织架构」都按这份名单画，改名单就好，不用动 3D 程序：

- **客服部**（`main: true`）是主要办公区，分四个小组 `teams`，每组一块对坐的工位：名字审核组、技术单审核组、Claude 客服组、新功能工位
- **其他部门**：营销、财务、人事、法务、数据，各一间小办公室；东边最多 6 间
- 小组 / 部门的 `kind`：`site`（网站里的工具，点员工进入 `href`）、`claude`（Claude 里的 skill，点员工复制 `/插件:skill` 指令）、`planned`（空工位 / 空办公室）
- **设施** `facilities`：把连接器按用途分进收发室、档案室、会议室、设计工作室、影音室、机房
- **墙上的画** `art`：从 Unsplash 载入，载不到会换成程序画的抽象画

加新功能：把客服部的「新功能工位」改成 `kind: 'site'`，填上 `href` 和员工。

## 公司模拟

- **每个人都不一样**：有膝盖、手肘，五官、7 种发型、6 种穿着、眼镜、高矮；名单里可以写 `look` 指定
- **性格和关系**：每人一个性格；同组的人比较熟，交接、聊天会更熟；资料卡显示最熟的同事
- **需求和心情**：每位员工有精力、饱足、如厕、社交、乐趣五项需求，坐着工作会慢慢下降；最低的那项掉到一半以下，员工会自己去补（累了泡咖啡、饿了去茶水间、无聊去休息区、想聊天去找同事）。五项平均就是心情
- **想法和对话**：员工起身时头上冒想法图示；找同事讨论、开会时会冒对话
- **游戏时钟**：左下角，真实 1 秒 = 游戏 1 分钟，08:00–20:00 一天；可以暂停、2 倍、4 倍速；天色跟着时间变
- **指挥员工**：点员工，资料卡里「叫他去」泡咖啡、吃点心、洗手间、开会、休息区、回座位
- **放低墙壁**：左下角，看清楚房间里面
- 需求、去处、对话的设定在 `hq/office.js` 开头的 `NEEDS`、`ACT`、`CHATS`
- 网址加 `?debug`，主控台可以用 `hqOffice`（例如 `hqOffice.info()` 看绘制次数）

### 资料存在哪里（还没有后端）

团队对话、工单、任务现在存在**这台电脑的浏览器**（`command-src/src/lib/live.ts`），同一台电脑的分页即时同步，换一台电脑看不到；权限还是网页登入。
要「全公司即时对话 + 服务器端检查权限」，需要后端。建议用 **Supabase 免费方案**：注册后在 claude.ai 连上 Supabase connector（或装 Supabase 插件），我把 `live.ts` 换成 Supabase 的资料表 + Realtime + RLS 权限（国内客服只能读写 2F 的资料），界面不用改。

### 改指挥中心

原始码在 `command-src/`（Vite + React + TypeScript + Tailwind + React Three Fiber + Lucide），打包到 `command/`。资料和界面分开：

| 文件 | 内容 |
|---|---|
| `command-src/src/data/floors.json` | 楼层和房间平面（36 × 22 公尺，中间走廊、电梯核心不能压） |
| `command-src/src/data/departments.json` | 部门在哪层、哪个房间；写 `team` 的用 `hq/company.js` 真实名单 |
| `command-src/src/data/people.json` | 示范员工、示范 AI 员工 |
| `command-src/src/data/tasks.json` 等 | 任务、项目、公司对话、AI 建议 |

```
cd command-src
npm ci           # 第一次
npm run check    # 检查资料（重复 id、房间重叠、部门房间不存在…）
npm run build    # 检查 + 型别检查 + 打包到 ../command/
```

改完把 `command-src/` 和 `command/` 一起提交。

树是 [ez-tree](https://github.com/dgreenheck/ez-tree)（MIT）程序化产生的真实树（树皮、树叶贴图、会随风摆），内嵌在 `command-src/src/vendor/ez-tree/`，只留几张缩小的贴图（约 400KB）；地板的木纹、石材、地毯、机房地板是 canvas 当场画的，不用下载图片。Claude 的专用 skill：`.claude/skills/command-center`（加楼层 / 部门 / AI 员工）、`.claude/skills/hq-new-tool`（加新审核工具并接进登入、3D 总部、指挥中心）。

## 派任务给 AI 团队（云端 + 每小时自动执行）

流程：**你派任务 → AI CEO（Aria）规划、分团队 → 审核部看计划、给意见 → 团队执行（开发组写程序）→ 审核部验收 → 你看成果**。

- 入口：指挥中心左边「派任务给 AI 团队」，或右边 AI CEO 卡片的「派任务」。
- 资料在 **Supabase**（免费版，新加坡机房，项目 `shuyi-hq` / `xmtljgxdzhrptsazklls`）：对话、工单、任务、missions、mission_events、CEO 报告。
  - 登入首页时顺便登入云端（`hq/auth.js` 的 `cloudLogin`）。第一次登入，后端用同一套密码 hash 再验一次才建立云端账号；密码不存在任何地方。
  - 谁能看什么由**后端权限（RLS）**把关：客服账号只看得到 2F 的对话和任务，老板看全部。
  - 连不上云端（例如网络问题，或这次更新前就登入了）→ 自动用**本机模式**，右上角会提示「请重新登入」。AI 团队只看得到云端资料。
- AI 团队：每小时由自动执行的 Claude 跑一轮，规则在 `.claude/skills/company-worker/SKILL.md`。写程序的任务会开 PR，**你说「合并」才会上线**，AI 团队不能自己合并。
- 3D 办公室：AI 团队把讨论写进对话、时间排在接下来一小时，所以整个小时都看得到他们在讨论；没有任务时偶尔「闲聊」（会标示）。
- 5F 新增**审核部**；每个 AI 员工的 `skill` 就是他真正用的 agent / skill（`command-src/src/data/people.json`）。

## 国内访问

- 不用 Google 字体，改用电脑自带的中文字体（苹方、微软雅黑、宋体 / 细明体）
- 指挥中心的 React、Three.js 等全部打包在 `command/assets/`，不连外网

- 显示不了 3D 的电脑，右上角「看组织架构」一样可以用
- 整个网站是静态文件，放到任何能放网页的地方都能用

## 加新功能

1. 新建一个文件夹，例如 `contract/index.html`
2. 要读写 Excel 就用 `../vendor/exceljs.min.js`、`../vendor/jszip.min.js`
3. 页面左上角放一个 `<a href="../">审核总部</a>` 回首页
4. 在 `hq/company.js` 把客服部的「新功能工位」改成 `kind: 'site'`，填 `href` 和员工
5. 要在浏览器里存东西（`localStorage`），名字前面加上这个功能自己的前缀，避免和别的功能撞名。现在用的：名字审核 `mzys_`，技术单 `tsr-`
